## 2. Long Description
**Drop a pin. Let AI fix the bug.**

Pinmark is the ultimate visual feedback and diagnostic tool built for developers and AI agents. Instead of manually writing out steps to reproduce or copying stack traces, simply click on any broken element on your screen. 

Pinmark automatically captures the full context of the bug, including underlying performance metrics, failed network requests, accessibility violations, runtime errors, and even the application state (Redux, Vuex, Zustand).

Designed specifically to work with the Model Context Protocol (MCP), Pinmark syncs these rich diagnostic snapshots directly to your AI assistants (like Claude, Cursor, or your local agents). Your AI can read the exact DOM state, view the captured error traces, and instantly suggest root-cause fixes.

### 🎯 Key Features:
- **One-Click Visual Pins:** Point, click, and leave a comment on any UI element.
- **Deep Diagnostics Engine:** Automatically captures:
  - ⚡️ Performance (Long tasks, FPS drops)
  - 🌐 Network Failures (Failed API calls correlated with your click)
  - ♿️ Accessibility (WCAG contrast & missing labels)
  - 🐛 Runtime Errors (Traces mapped to the pinned element)
  - 📦 State Snapshots (Redux, Vuex, Zustand)
- **AI-Native Auto-Triage:** Automatically categorizes bugs by severity and impact before you even look at them.
- **Instant MCP Sync:** Feeds rich, structured diagnostic JSON directly to your AI agent for automated debugging.
- **Developer Review UI:** Clean, brutalist popup to review all pending pins, view Markdown-ready AI fix plans, and copy data with one click.

### 🔒 Privacy & Local-First
Pinmark respects your data. It connects directly to your local MCP server. No middleman cloud syncing required for the local agent workflow. The diagnostic data stays between your browser and your local AI environment.
