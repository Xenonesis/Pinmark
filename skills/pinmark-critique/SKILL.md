# Pinmark Critique Mode

Use this skill when the user asks to "critique my UI", "review design on localhost", or "run Pinmark critique":

## 1. Browser Exploration
1. Launch browser to the target web application (e.g. `http://localhost:3000` or `http://localhost:5173`).
2. Scroll through the page systematically from top to bottom (Hero, Features, Pricing, Footer).

## 2. Identify UI/UX Issues
Look for:
- Visual hierarchy and alignment flaws.
- Inconsistent spacing, padding, and margins.
- Color contrast and typography sizing.
- Missing responsive behavior or awkward wrapping.

## 3. Submit Pinmark Annotations
Submit 3–7 high-value feedback annotations with precise selectors, severity levels (`blocking`, `important`, `suggestion`), and clear actionable recommendations.
